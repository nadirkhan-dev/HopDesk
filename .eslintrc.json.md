`no-unsafe-declaration-merging` is disabled deliberately.

Merging a `declare interface` with a class is the standard way to give an
EventEmitter subclass typed `on()` overloads — it is how Node's own type
definitions are written. The rule exists to catch *accidental* merges; here it
is intentional, and the alternative (a generic typed-emitter wrapper) is more
code for less readable call sites.
